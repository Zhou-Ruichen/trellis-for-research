# Project Layout

Follow the project's existing layout. For a new project, create only the
directories used by the current calculation. A direct script or notebook is
enough for exploratory work; a package, configuration system, test directory,
or command-line wrapper is optional.

Keep temporary files and large generated data outside Git by default;
record a path, URL, object key, or checksum in the current record rather
than moving outputs to satisfy this guideline. Keep the existing layout
and adapt examples to it.
