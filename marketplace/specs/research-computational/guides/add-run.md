# Guide: Add A Run

Use for a new analysis, simulation, traditional ML experiment,
data-processing run, or evaluation.

1. State the scientific question and the minimal comparison that answers it.
2. Find the project's existing script, notebook, config, data, and result
   record; reuse that path and change parameters or config.
3. Run the cases the question needs under matched conditions, with data
   isolation and units made clear.
4. Record the actual command or settings, observed results, limitations,
   and output paths in the project's existing record.

Keep variants as parameters or configuration values. Execution and checking
rules are in [research-minimal.md](../shared/research-minimal.md).
