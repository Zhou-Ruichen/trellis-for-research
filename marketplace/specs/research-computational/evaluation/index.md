# Evaluation Guidelines

Use the smallest comparison that helps answer the question. When two cases
are compared, state what stayed the same, what changed, the data used, and the
units of the reported number. Check a data or input assumption when getting it
wrong could silently change the result; let ordinary errors fail normally.

A comparison distinguishes the explanations at issue in the current
question. Give each new case one named change from its reference condition
and carry over the data, settings, and seeds. When several factors are in
play, name each factor's levels and the combinations actually run, and keep
existing runs and proposed new cases distinct in the plan. Add a case when
the results so far cannot distinguish the explanations or the added case
could change the conclusion. Interpret a near-equal result together with
the variation and the comparison's resolving power, at the level of
explanation the design isolates. When the question is answered, record the
result and stop.

If a model or parameter was chosen using data, say which data were used for
that choice and which data produced the reported number. Use a separate
evaluation set when the question needs an estimate on unseen data.

Repeat a run or report variation when the question is about stability or a
difference between conditions; the scale of repetition follows the question
and the available resources. The recorded numbers describe the difference
observed in this comparison. A claim about stability or general superiority
rests on the repeated-run evidence that shows it. A single run is described
as one observation, with the claim's precision matched to the information in
that run. When conditions share data or folds, report the paired per-fold
differences.

Record the actual number, condition, metric definition, and any output path
needed to rerun it. State run counts, units, and variation as the records
contain them; what the records do not contain stays unknown. Report an
unexpected, negative, or null result with its observed value.
