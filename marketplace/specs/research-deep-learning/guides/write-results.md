# Write Research Results

Use [scientific-writing.md](../shared/scientific-writing.md) for
manuscripts, abstracts, captions, and research-facing reports.

Read the available analysis, tables, figures, or cited sources, then draft
the supported finding, evidence, and interpretation. Do not create a new
experiment just to complete a writing task; identify missing evidence when
it limits a requested claim. Link to existing records as needed; commands,
settings, software versions, and checkpoints belong in Methods or
reproducibility notes, not in place of the scientific finding.

A run that only establishes executability does not establish scientific
performance, and task completion does not approve a claim for publication.
